# v3.0 Material Understanding Baseline

APEX Vision AI now supports an `auto` material profile for render requests.

## Behaviour

`material_profile=auto` runs the deterministic material-understanding baseline against the catalog tile texture and resolves one of:

- ceramic
- stone
- wood
- vinyl
- carpet

The classifier also reports:

- confidence
- texture scale factor
- texture variance
- edge density
- periodicity
- classifier method/version

The selected profile is then passed into the existing material rendering engine.

## Important accuracy boundary

This is a deterministic baseline, **not a trained AI classifier**. The confidence value is a rule-confidence signal and must not be represented as production classification accuracy.

A production learned classifier requires a versioned labelled dataset covering ceramic, vitrified tile, marble, granite, wood, vinyl, carpet, wall tile and sanitary surfaces, with a held-out evaluation set.

## Compatibility

The default API profile remains `generic`, so existing render clients retain their previous behaviour. `auto` is opt-in until the production benchmark establishes acceptable classification quality.
