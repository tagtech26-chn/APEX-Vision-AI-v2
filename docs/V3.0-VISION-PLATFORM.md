# APEX Vision AI v3.0 — Vision Platform

## Scope

v3.0 remains strictly within **APEX Vision AI**. No ERP, artwork, or other APEX modules are introduced.

## First capability: material-aware rendering

The renderer now accepts an explicit `material_profile`:

- `generic`
- `ceramic`
- `stone`
- `wood`
- `vinyl`
- `carpet`

The profile controls deterministic texture enhancement parameters while the existing geometry, lighting, color matching, projection, and occlusion pipeline remains unchanged.

### API example

```json
{
  "room": 1,
  "tile": 1,
  "tile_size": 600,
  "pattern": "Straight",
  "material_profile": "stone"
}
```

## Engineering rule

Material profiles are intentionally configuration/data driven. They do not claim AI classification accuracy. AI-based material classification will be introduced only when a provider and representative validation dataset are available.

4. Material-specific lighting and reflectance handling
5. Advanced occlusion confidence
