# APEX Vision AI v2.1 — Sprint 1

## Production hardening

Sprint 1 establishes the production-operability baseline for APEX Vision AI.

### Reliability

- Safe unhandled API exception responses.
- Health and readiness probes.
- Bounded render jobs with expiry and supersession handling.
- Explicit render output write failures.

### Security

- Production CORS requires explicit configured origins.
- Render output is not browser-cached.
- Scene cache uses HMAC integrity protection when enabled.
- Cache writes are atomic.
- Unsafe cache path components are rejected.
- Diagnostics do not expose model paths or secrets.

### Observability

- Centralized configurable logging.
- AI provider diagnostics.
- Render duration metrics.
- Cache hit/miss/error metrics.
- Render failure and completion logging.

### Frontend resilience

- API timeout configuration.
- Retry handling for safe GET requests.
- Bounded render polling.
- Catalog loading and retry states.
- Responsive gallery dimensions.

### Testing and CI

- Configuration validation coverage.
- API health/readiness/diagnostics contract coverage.
- Render metrics coverage.
- Render service/cache regression coverage.
- Backend pytest validation.
- Frontend lint/build validation.
- Production container smoke testing.

## Validation gate

The branch is implementation-complete for Sprint 1 only after the GitHub Actions
workflow passes all backend, frontend, container, and smoke-test jobs.
