# v3.0 Material Intelligence Benchmark

## Purpose

APEX Vision AI now has a model-agnostic evaluation layer for material and finish classification. It reports accuracy, macro precision, macro recall, macro F1, and a confusion matrix.

The evaluator does **not** claim production AI accuracy without labelled data.

## Ground-truth dataset contract

Each benchmark record should contain:

- `image_id`: stable identifier for the source image
- `split`: `train`, `validation`, or `test`
- `material`: one of the supported material labels
- `finish`: `matte`, `satin`, or `gloss` when known
- `surface_mask`: optional ground-truth surface mask reference
- `texture_scale`: optional measured reference scale

The production quality benchmark must use a held-out `test` split that is never used to tune classifier rules or model weights.

## Required reporting

For every benchmark execution report:

- sample count
- material accuracy
- material macro precision
- material macro recall
- material macro F1
- material confusion matrix
- finish metrics when finish labels are available

For future surface-detection evaluation, add IoU and boundary F1 against human-labelled masks. For texture-scale estimation, report MAE against measured references.

## Quality gates

Do not introduce arbitrary thresholds before a representative labelled dataset exists. Once the dataset is established, CI thresholds should be versioned alongside the dataset manifest and classifier/model version.

A benchmark failure must fail CI rather than being converted into a warning.
