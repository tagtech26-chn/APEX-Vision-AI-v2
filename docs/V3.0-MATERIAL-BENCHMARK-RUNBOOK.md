# v3.0 Material Benchmark Runbook

The benchmark is model-agnostic and evaluates predictions produced by the real classifier. It never creates predictions itself.

## Prediction contract

Provide a JSON list with one object per held-out `test` record:

```json
[
  {
    "id": "sample-001",
    "material": "ceramic",
    "finish": "gloss"
  }
]
```

`id` must match the benchmark manifest. Every held-out test sample must have exactly one prediction.

## Run locally

```bash
python scripts/run_material_benchmark.py \
  --manifest data/benchmarks/materials/v1/benchmark.json \
  --predictions predictions.json \
  --output material-benchmark-report.json
```

For an approved production-labelled dataset, add `--require-production`. The command will refuse to evaluate a dataset that is not explicitly marked `production`.

## Release evidence

A production release must retain:

- dataset version and provenance
- held-out test sample count
- material accuracy, precision, recall and macro-F1
- finish accuracy, precision, recall and macro-F1
- confusion matrices
- evaluation commit SHA
- evaluation date

The current repository fixture is intentionally marked `ci-fixture`; its results are regression-test plumbing only and must not be reported as real-world AI accuracy.
