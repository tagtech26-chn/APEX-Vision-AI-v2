# v3.0 Material Quality Gate

The APEX Vision AI material benchmark now has two separate controls:

1. **Contract gate** — always active in CI. It validates dataset structure, labels, provenance and versioning.
2. **Production quality gate** — available but intentionally inactive for the current `ci-fixture` dataset.

## Production activation

The production gate may only be activated when all of the following are true:

- Dataset status is `production`.
- Dataset identity matches the configured gate.
- At least 100 held-out `test` samples exist.
- Measured material accuracy >= 0.90.
- Measured material macro-F1 >= 0.90.
- Measured finish accuracy >= 0.85.
- Measured finish macro-F1 >= 0.85.

These thresholds are release criteria, not claims about the current classifier.

## Evidence requirements

Before activation, the dataset owner must record dataset version, provenance, label distribution, collection/evaluation date and separation of development and held-out test data. Customer or personal images must not be committed without appropriate authorization.

The quality evaluator consumes measured metrics produced by the benchmark evaluator. It does not manufacture predictions, accuracy values, or confidence claims.
