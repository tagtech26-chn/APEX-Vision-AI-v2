# v3.0 Material Intelligence

APEX Vision AI now has a deterministic material-intelligence baseline that estimates both surface material and finish before rendering.

## Signals

The baseline extracts:

- texture variance
- edge density
- periodicity
- highlight ratio
- local contrast

These signals produce:

- material profile: ceramic, stone, wood, vinyl, or carpet
- finish: matte, satin, or gloss
- confidence score
- texture scale factor

## Rendering path

`material_profile=auto` performs classification and passes the resulting material and finish intelligence into the material renderer. Explicit material profiles remain supported and use a stable satin default unless a future API contract adds explicit finish selection.

The renderer applies bounded texture sharpening, finish-specific contrast and controlled highlight response.

## Accuracy policy

This is a deterministic baseline, not a trained AI model. The confidence value is a rule-based confidence signal and must not be interpreted as model accuracy.

Production AI classification should only replace this baseline after a labelled dataset, held-out benchmark, class-level precision/recall, and regression threshold are established.

## Validation

Coverage includes deterministic classifier output, invalid-input handling, feature reporting, finish stability, finish-aware rendering, and bounded texture-scale behaviour.
